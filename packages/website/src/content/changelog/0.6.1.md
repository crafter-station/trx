### Fixed
- **`--output-dir` now creates the directory when it does not exist** ([#23](https://github.com/crafter-station/trx/issues/23)) — pointing `--output-dir` at a new path used to die on the first ffmpeg step with `ffmpeg audio cleaning failed (exit 254)`, a message that named ffmpeg while the real cause was the missing directory. Chunking already created its own output directory, but that step runs after the pipeline writes the cleaned WAV, so it was never reached. The pipeline now creates the directory up front, covering both the download and the clean paths.

### Upgrade
```bash
bun add -g @crafter/trx@latest --force
trx --version # -> 0.6.1
trx talk.mp3 --output-dir ./new-folder
```
